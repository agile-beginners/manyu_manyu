# Product Steering

## プロダクト概要

このプロジェクトは、動画から操作マニュアルを自動生成する Flutter アプリケーションである。  
ユーザーが操作手順を録画した動画をアップロードすると、AI が動画を解析してステップを抽出し、画像注釈を付与したうえで編集可能なマニュアルとして保存・表示・PDF 出力できることを目指す。

## 中核ドメイン

このプロジェクトで継続的に中心となるドメイン集約は以下の 2 つである。

- **Manual 集約**
  - `Manual`
  - `ManualStep`
  - `ManualStatus`
  - 生成、編集、プレビュー、PDF 出力はすべてこの集約を中心に設計する
- **Video 集約**
  - `VideoFile`
  - 動画の選択、検証、保存、生成フローへの引き渡しを担う

## feature 境界の考え方

- feature は画面単位ではなく、**ユーザー行動を起点に発見したドメイン集約ごと** に切る
- 同じ集約を触る処理群は、画面が複数に分かれていても 1 つの feature にまとめる
- UI フローは `presentation/` 配下のサブフォルダで表現し、feature フォルダ自体は集約単位を優先する

## 現時点の責務境界

- `video` feature の責務は **`VideoFile` を返すところまで**
- `manual` feature は `VideoFile` を受け取り、Manual の生成、編集、プレビュー、出力を担う
- `video` から `manual` への受け渡しは、共有状態ではなく **画面遷移時の引数** を基本とする

## 継続方針

今後 feature を追加・整理する際も、まず「ユーザーは何をしたいか」を起点にしつつ、最終的には **どの集約を一貫して扱うか** で feature 境界を決める。  
画面数や UI フローの数だけで feature を分割しない。
